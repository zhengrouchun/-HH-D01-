HH-D01可以使用的引脚

**不用扩展板**

在保留 R200 和 USB 串口调试的前提下，可直接使用的只有：

| 引脚   | 建议用途              | 原因                           |
| ------ | --------------------- | ------------------------------ |
| GPIO12 | 普通输入/输出         | 未被当前 R200、USB 串口占用    |
| GPIO13 | 普通输入/输出，但谨慎 | 可能会影响板载外设，先单独测试 |
| GPIO14 | 普通输入/输出         | 未被当前 R200、USB 串口占用    |

这最多只有 3 路，无法满足 `3 个 LED + 蜂鸣器 + 3 个按键 = 7 路`。

不能使用的引脚及依据：

| 引脚         | 为什么不能用                      |
| ------------ | --------------------------------- |
| GPIO0-GPIO5  | QSPI0 Flash 数据、时钟、片选线    |
| GPIO6-GPIO11 | QSPI1 Flash 数据、时钟、片选线    |
| GPIO15       | 当前 R200 UART TX                 |
| GPIO16       | 当前 R200 UART RX                 |
| GPIO17       | USB 串口 TX，使用后不能正常看日志 |
| GPIO18       | USB 串口 RX，使用后串口通信受影响 |

SDK 将 GPIO0-5、GPIO6-11 定义为两组 QSPI Flash 线：[platform_core.h (line 473)](D:/ws/fbb/src/drivers/chips/ws63/include/platform_core.h:473)。你的实际测试也证明 GPIO6 接蜂鸣器后复位会 `Flash Init Fail` 或乱码，因为芯片在执行你的 GPIO 初始化代码前，就要先通过这些线读取 Flash。

因此，GPIO2、GPIO6、GPIO7、GPIO8 都不能再连接 LED、蜂鸣器、按键等外部电路。它们运行后可能暂时能工作，但复位时不可靠。

**使用 TCA9555 扩展板**

HH-D01 和扩展板只连接 4 根线：

```
HH-D01 3V3      -> TCA9555 VCC
HH-D01 GND      -> TCA9555 GND
HH-D01 GPIO12   -> TCA9555 SCL
HH-D01 GPIO14   -> TCA9555 SDA
```

若扩展板没有自带 I2C 上拉电阻，额外各接一个 `4.7kΩ`：

```
SCL -> 4.7kΩ -> 3V3
SDA -> 4.7kΩ -> 3V3
```

`A0、A1、A2` 都接 `GND`，I2C 地址通常为 `0x20`。`INT` 可以暂时不接，程序采用轮询读取按键。

外设连接建议：

```
P00 -> 红灯阴极；红灯阳极 -> 1kΩ -> 3V3
P01 -> 绿灯阴极；绿灯阳极 -> 1kΩ -> 3V3
P02 -> 黄灯阴极；黄灯阳极 -> 1kΩ -> 3V3

P03 -> 有源蜂鸣器模块 IN
3V3 -> 蜂鸣器 VCC
GND -> 蜂鸣器 GND

P10 -> 按键1 -> GND，P10 另接 10kΩ 上拉至 3V3
P11 -> 按键2 -> GND，P11 另接 10kΩ 上拉至 3V3
P12 -> 按键3 -> GND，P12 另接 10kΩ 上拉至 3V3
```

蜂鸣器必须是 `3.3V` 供电、`IN` 可识别 3.3V 的模块。若模块必须 5V 供电，不能将它的 `IN` 直接接 TCA9555，需要加三极管/MOSFET 电平隔离。
