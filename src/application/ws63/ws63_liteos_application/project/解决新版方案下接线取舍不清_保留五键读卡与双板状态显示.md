# 解决新版方案下接线取舍不清 保留五键读卡与双板状态显示

核对日期：2026-10-12。针对用户提供的三份文档，核对当前 ClearChain 双板工程的接线取舍。本次仅新增说明，没有修改代码、拆线、编译或烧录，也没有把拆线后的实板表现写成已验收。

## 结论与问题原因

现在优先保留板1的第一颗 TCA9555、S1～S5、R200，以及板2的 LCD。第二颗 TCA9555 和九个扩展键可以暂时不接。三色灯与外接蜂鸣器可以作为可选反馈附件，已有稳定接线建议先保留。

此前完整接线说明列的是全部现有元件的接法，容易被理解为每条线都必需。新版方案把完整界面和详情操作移到手机，设备保留读标签和状态显示，因此方向键与详情键不再是基本版的必需硬件。手机可以选阶段，但嵌入式规格第5节仍明确要求保留五个实体阶段键。

三份附件中的修改要求、团队分工、确认事项和日程作为规格内容阅读；本轮用户只问接线取舍，没有据此执行附件里的修改固件、联系队友或部署服务等事项。

## 可以暂时舍去的连接

1. 第二颗 TCA9555，地址为 0x21：P00～P03 对应上、下、左、右；P04 对应 OK；P10～P13 对应 D1～D4。可以取消九个键各自的按键接地支路和各自的 10kΩ 上拉支路，再取消第二颗自身的 VCC、GND、SCL、SDA 和地址选择连接。
2. 舍去第二颗后，方向/确认键和实体详情入口不能使用。规格明确十字键 v1 不使用、D 键可选；OK 没有基本版必需动作，省去 OK 属于功能范围判断。当前 API 应用的 consume_keys 也仅处理 S1～S5，因此扩展键已接上不代表相关页面操作已经实现。
3. 可选反馈：第一颗 TCA 的 P00/P01/P02 分别连接红、绿、黄 LED，可以取消这三个 LED 及各自限流电阻支路；P03 连接外接蜂鸣器，可以取消其 IN、VCC、GND 专属支路。代价是没有独立灯光或外接声音反馈，结果仍由 LCD 和手机显示。这不是规格要求必须取消。R200 自带提示音不是这个外接蜂鸣器。
4. 当前无需连接：LCD SDO/MISO、触摸接口、SD 卡接口、TCA 的 INT，以及 R200 的 CTS/RTS。当前屏幕驱动只写数据，按键轮询，R200 未使用硬件流控。R200 既有正常使能设置不随意拆除。
5. 当前两块板之间通过 SLE 无线传状态，不需要板间 UART/I2C/SPI 数据线。手机和后端通过 Wi-Fi/HTTP 与板1通信，不需要业务串口线；USB 供电和日志调试连接仍按需要保留。

拆第二颗时只移除它自己的分支。若第一颗的电源、地或总线经第二颗模块跳接，先把第一颗改为直接接板1。确认第一颗的 SCL/SDA 仍有到 3.3V 的总线上拉；不能把按键上拉与总线上拉混为一组一起拆掉。

## 必须保留的当前接线

### 最小方案元件清单

- HH-D01/WS63 开发板2块：板1负责读卡与按键，板2负责显示；各保留 USB 供电/调试线。
- TCA9555 模块1颗：使用第一颗，地址0x20。
- 实体按键5个：S1～S5；10kΩ按键上拉电阻5只。
- R200 UHF读卡模块1个、匹配天线1套、配套UHF标签。
- ST7796 LCD + 35002 SPI转接板1套。
- R200用稳定5V电源；LCD用稳定3.3V电源，可由5V经降压模块获得。TCA及按键上拉由板1的3V3供电。
- 杜邦线、公共地/电源分配连接；确认TCA的SCL/SDA已有到3.3V的总线上拉，没有时各补约4.7kΩ。模块已有总线上拉时不重复叠加。

下面列的是当前固件所需的目标接法，不表示本轮已检查用户实物。GPIO编号按板上信号丝印识别；35002的接口编号不可套用裸屏排线。

- 板1 → 第一颗 TCA：3.3V、GND、GPIO13 → SCL、GPIO14 → SDA；第一颗 A2/A1/A0 接地，地址为 0x20。
- 第一颗 P10/P11/P12/P13/P14 → S1/S2/S3/S4/S5；每个键接地，每个输入各保留 10kΩ 到 3.3V 的上拉。
- 板1 GPIO15/TXD1 → R200 RX，板1 GPIO16/RXD1 ← R200 TX；保留稳定 5V 供电、R200 与板1共地及匹配天线。
- 板2 GPIO7 → LCD SCK，GPIO9 → MOSI，GPIO8 → CS，GPIO1 → DC，GPIO14 → RESET。
- LCD 保留稳定 3.3V 供电、与板2共地和 LED/BL 到 3.3V。可以省背光 GPIO 调节线，不能省背光所需连接。
- 两块开发板分别供电。板1的 GPIO14 是 TCA SDA，板2的 GPIO14 是 LCD RESET，不能因为同名而互接。

每个阶段键的两条支路是“对应Pxx → 按键 → GND”和“对应Pxx → 10kΩ → 3.3V”，电阻不是串在按键接地线上。

R200电源负极、R200 GND和板1 GND接在一起；LCD电源负极、LCD GND和板2 GND接在一起。屏幕使用外部3.3V供电时，只与板2共地，不把外部3.3V正极和板2的3V3输出并联。板1和板2的3V3输出也不并联；SLE无线通信不要求额外跨板信号线或独立地线。

这些 GPIO 是信号编号，不是排针序号；TCA 的 P10 是端口1第0位，也不是开发板 GPIO10。上述 LCD 接法针对既有 ST7796 + 35002 SPI 模块，不直接套用于裸屏40针排线。

## 新版功能有什么变化

完整界面由手机负责，包括历史、原始阵列、图像、直方图和风险详情；设备 LCD 显示模式、扫描进度和结果。原始阵列仅 CP 可看，当前图像仅 S4/S5/CP 可看，是否允许由后端决定。

S1～S5 实体键保留，正常联网业务中按键发命令，以后端返回状态为准，再同步手机与设备屏幕。CP 实体键在规格里仍待定，基本方案由手机选择即可；START_SCAN、STOP_SCAN、RESET 是 API 命令，不意味着要再装三个实体按钮。业务 RESET 不等于开发板硬件复位。

三份附件规定手机和 WS63 都访问中间后端，通常每500ms取状态。当前源码进一步按角色把板1的状态通过 SLE 发给板2显示；附件没有具体要求拆掉现有板2。取消板2需要重新分配屏幕引脚、驱动和构建角色，不能当作本次可直接拆线的精简项。

文档建议 320×480 和 LVGL，当前代码实际采用 480×320 横屏及现有 LCD/UI 驱动；此次不因建议尺寸改变引脚或认定当前已改为 LVGL。旧 /scan 主流程转向 /device/state、/device/command、/device/scan 属于软件接口变化，不改变 R200 TX/RX 和 LCD SPI 接线。

离线测试包用于验证读卡和显示；手机同步、真实审批结果与风险仍需启用 HTTP 并接通实际后端。省线不会自动补齐后端联调。

## 拆线后的复查顺序

1. 全部断电，优先移除第二颗及九键专属支路，保留第一颗电源、地、总线、地址和上拉。暂不为了省线改变已稳定的灯和蜂鸣器。
2. 通电确认第一颗正常；第二颗未接时出现 Extra keys unavailable: TCA9555 0x21 probe failed 属预期。若第一颗也失败，先排查被一起拆掉的公共连接。
3. 分别按 S1～S5，确认对应阶段输入；使用现有离线测试流程验证真实 EPC/RSSI，再确认板2显示随板1变化。
4. 接通真实后端后，再验证实体键与手机同步、CP、Start/Stop 和最终业务结果。拆线后的稳定性需用实际日志和画面确认。
