# 解决双板元件接线混乱与旧引脚说明冲突：完整接线及逐项检查

核对日期：2026-10-11。对应当前 ClearChain 主工程，两块 HH-D01/WS63、R200、两颗 TCA9555、14 个按键、红绿黄 LED、有源蜂鸣器和 ST7796 + 35002 SPI 转接板。

**接线范围补充：本文件列的是全部现有元件的接法，不代表基本版必须接齐14键。** 根据用户随后指定的五份规格，方向键v1不使用，D键可选，OK无必需动作；基本版可以不接第二颗TCA及其九键。保留第一颗与S1～S5、R200、LCD；灯和蜂鸣器可作为后接反馈附件，但已有正常接线建议保留。依据及省线范围见[五份规格核对及可省接线清单](解决把完整元件接线误当基本版必需_五份规格核对及可省接线清单.md)。

本次核对了实际参与编译的源码、板卡与模块手册、此前实板记录；整理的是当前固件要求的目标接法，尚未看到你这次接乱后的实物，不能替代重新接线后的通电验收。用户已确认蜂鸣器为3.3V、低电平触发、VCC/GND/IN三脚模块，接法见第5节。没有修改、编译或烧录固件。

## 1. 先认清板号、编号和电源

- **板1 / Board A**：读卡控制板，接 R200、两颗 TCA9555、全部按键、三色灯、蜂鸣器；正常双板固件为 SLE Server。
- **板2 / Board B**：显示板，只接 LCD；正常双板固件为 SLE Client。
- 两块板之间通过 SLE 无线通信，不接 TX/RX、SCL/SDA 或 SPI 数据线。
- **GPIO13 是信号名称，不是排针第13脚。** 板上 GPIO07 与 GPIO7 是同一个信号。
- **TCA 的 P10 是端口1的第0位，不是开发板 GPIO10，也不是芯片第10脚。** 有的模块写 P1.0、IO1_0，核对它的丝印含义。
- R200 使用稳定 **5V**；TCA 使用 **3.3V**；35002 LCD 的 VCC 和背光控制 LED 使用 **3.3V**。
- 重新接线先断开两块板 USB 和外部电源，连线完成后再通电。用标签标出“板1”“板2”“TCA 0x20”“TCA 0x21”。

### 调试时采用的电源分配

```text
电脑 USB → 板1 USB接口                      为板1供电并保留日志串口
板1 3V3 → TCA #1和TCA #2的VCC              为两颗扩展器供3.3V
板1 3V3 → 按键上拉电阻、三个LED限流支路      为按键和灯提供3.3V
外部稳定5V正极 → R200 VCC                  为读卡器供电
外部5V负极 → R200 GND、板1 GND             使读卡串口有共同电平参考

电脑 USB → 板2 USB接口                      为板2供电并保留日志串口
屏幕专用稳定3.3V正极 → LCD VCC、LCD LED     为屏幕供电并固定打开背光
屏幕3.3V负极 → LCD GND、板2 GND             使屏幕与板2信号共地
```

若屏幕使用 5V 转 3.3V 降压模块：模块 IN+ 接稳定5V，IN− 接该电源负极；先不接屏幕，用万用表确认 OUT+ 对 OUT− 为3.3V，再把 OUT+ 接 LCD VCC/LED、OUT− 接 LCD GND/板2GND。这些名称按你模块的实际丝印对应。

**外部3.3V输出不能与开发板3V3输出直接并联；两块板的3V3输出也不能并联。** 现在保留开发板USB供电，不额外向其VIN/5V排针送电。R200不要从开发板3V3取电。屏幕电源和板2应一起通断，避免一边断电而另一边继续通过信号线供电。

板1这一组必须共地：板1、两颗TCA、全部按键、LED支路、蜂鸣器、R200及R200电源负极。板2这一组必须共地：板2、LCD及LCD电源负极。两组独立供电时，SLE不要求额外跨板地线；若用同一外部电源，两组地自然随该电源共地。

## 2. 板1接两颗TCA9555

### 两颗模块共用的四根线

```text
板1 3V3   → TCA #1 VCC 和 TCA #2 VCC       两颗均用3.3V供电
板1 GND   → TCA #1 GND 和 TCA #2 GND       两颗均与板1共地
板1 GPIO13 → TCA #1 SCL 和 TCA #2 SCL      共用软件I2C时钟
板1 GPIO14 → TCA #1 SDA 和 TCA #2 SDA      共用软件I2C数据线
```

这两颗是并接到同一条总线，第一颗和第二颗不能交换SCL/SDA。**当前SCL是GPIO13，旧笔记的GPIO12不适用。** 板1GPIO13还连接板载用户键，运行时不要按这个用户键；它不是复位键。

此前笔记说明两颗模块各有SCL/SDA到VCC的10kΩ上拉；若仍是这两颗，接齐后每条总线相当于约5kΩ，不用另外叠加一组。若实际模块没有上拉，则SCL和SDA各用一只约4.7kΩ电阻上拉到3.3V。**总线上拉不能接5V；它和每个按键的上拉是不同支路。**

### 地址选择

```text
TCA #1：A2 → GND，A1 → GND，A0 → GND      7位地址0x20
TCA #2：A2 → GND，A1 → GND，A0 → 3V3      7位地址0x21
两颗 INT → 暂时不接                        当前程序轮询读按键
```

地址脚不能悬空。如果用模块焊盘/跳帽选择地址，按其原理图设置，不要把已经接地的A0直接再接3V3造成短路。标准TCA9555芯片没有独立RESET脚；不要把INT当RESET。

0x20和0x21是两颗器件的地址，不是GPIO，也不是端口编号；若工具问的是7位地址，直接填写这两个值。

## 3. 全部14个按键

### 每一个按键都采用同一结构

```text
3.3V ── 10kΩ上拉电阻 ──┬── TCA的指定输入Pxx
                       │
                      按键
                       │
                      GND
```

上拉电阻接在Pxx与3.3V之间；按键接在Pxx与GND之间。**不是把电阻串在“Pxx→按键→GND”这条线上。** 松开输入为高，按下接地为低。

完整接齐需14条按键支路，按当前方案每条配一只10kΩ电阻。TCA9555本身有弱内部I/O上拉；外接10kΩ是当前工程的明确接线方案，不是因为这颗芯片完全没有内部上拉。模块带I2C上拉不代表各Pxx已经有10kΩ上拉。

四脚轻触按键先用断电通断档找出“松开不通、按下才通”的两组触点，再各选一脚接Pxx/GND；不能只凭脚在同侧或对侧判断。接到本来就短接的两脚，会一直被判定为按下。

### TCA #1，地址0x20：五个阶段键

```text
P10 → S1按键 → GND；P10另接10kΩ到3.3V     第1阶段键
P11 → S2按键 → GND；P11另接10kΩ到3.3V     第2阶段键
P12 → S3按键 → GND；P12另接10kΩ到3.3V     第3阶段键
P13 → S4按键 → GND；P13另接10kΩ到3.3V     第4阶段键
P14 → S5按键 → GND；P14另接10kΩ到3.3V     第5阶段键
```

### TCA #2，地址0x21：方向/确认与D键

```text
P00 → 上键   → GND；P00另接10kΩ到3.3V     日志Extra key 1
P01 → 下键   → GND；P01另接10kΩ到3.3V     日志Extra key 2
P02 → 左键   → GND；P02另接10kΩ到3.3V     日志Extra key 3
P03 → 右键   → GND；P03另接10kΩ到3.3V     日志Extra key 4
P04 → OK键   → GND；P04另接10kΩ到3.3V     日志Extra key 5
P10 → D1按键 → GND；P10另接10kΩ到3.3V     日志Extra key 6
P11 → D2按键 → GND；P11另接10kΩ到3.3V     日志Extra key 7
P12 → D3按键 → GND；P12另接10kΩ到3.3V     日志Extra key 8
P13 → D4按键 → GND；P13另接10kΩ到3.3V     日志Extra key 9
```

第一颗P03接蜂鸣器，第二颗P03接右键；器件地址不同，互不冲突。未使用端口留空，不自行改作新按键。当前没有独立CP物理键，不占用OK/D4代替。

当前API应用只消费S1～S5作为阶段操作；检测到方向/OK/D键不等于LCD导航和业务功能已实现。日志availability=1也不等于接线坏了。此前记录已验过第二颗九路输入，但你这次重接后仍应逐键检查。

## 4. 三个LED：全部接第一颗TCA

```text
板1 3V3 → 独立470Ω～1kΩ电阻 → 红LED阳极；红LED阴极 → TCA #1 P00
板1 3V3 → 独立470Ω～1kΩ电阻 → 绿LED阳极；绿LED阴极 → TCA #1 P01
板1 3V3 → 独立470Ω～1kΩ电阻 → 黄LED阳极；黄LED阴极 → TCA #1 P02
```

每行是一条独立限流支路，三只LED需要三只电阻。裸LED通常长脚为阳极、短脚/外壳平边侧为阴极；脚剪短后用二极管档确认。代码采用低电平点亮，LED阴极接Pxx，不直接接GND。此接法适用于分立裸LED；自带电路的灯模块需要按模块接口另核对。

## 5. 蜂鸣器：第一颗TCA的P03

用户已确认实物为3.3V、低电平触发、VCC/GND/IN三脚模块，与当前蜂鸣器开/关控制方案对应。断电后直接按下面接：

```text
蜂鸣器 VCC → 板1 3V3                  为模块供3.3V，不接R200的5V
蜂鸣器 GND → 板1公共GND                与第一颗TCA共地
蜂鸣器 IN  → TCA #1（地址0x20）的P03    控制信号，拉低响、拉高停
```

VCC是供电脚，IN是控制脚，不能交换。IN接第一颗P03，不接第二颗P03（第二颗该脚是右键），也不接开发板GPIO3。按当前驱动，P03输出低电平时响，高电平时停止。这是带驱动电路的三脚模块接法，不能套用到两脚裸蜂鸣器。

R200本身的提示音和这只外接蜂鸣器是不同器件；R200有声不证明P03接线正确，也不证明板1收到标签数据。

## 6. R200：板1的UART1

```text
稳定5V电源正极 → R200 VCC               为读卡器供电
5V电源负极     → R200 GND               电源回路
板1 GND        → R200 GND               串口共同电平参考
板1 GPIO15/TXD1 → R200 TTL_RX / RXD      板1发命令、R200接收
板1 GPIO16/RXD1 ← R200 TTL_TX / TXD      R200回数据、板1接收
R200射频接口   → 配套匹配天线             先接天线再上电/读卡
```

**TX接对方RX、RX接对方TX。** R200用TTL串口，不把真正RS232接口接到WS63 GPIO。按此前模块方案使用3.3V TTL；若换了模块/转接板，要先确认TX高电平，5V TTL需转换后再进板1RX。5V供电不代表串口是5V电平。

当前设置：UART1、115200波特率、8数据位、1停止位、无校验、无硬件流控；只接TX/RX/GND，不需要CTS/RTS。R200的EN/GPIO等未在当前适配代码里使用，保持模块既有正常配置，不随意接开发板引脚。按模块丝印接，不猜R200排针从左向右的脚序。

## 7. ST7796 + 35002 SPI屏幕：只接板2

以下序号是**35002转接板14针接口的序号**，不是裸屏40针排线的编号。

```text
LCD 1 VCC        → 屏幕专用稳定3.3V       模块电源，不接5V
LCD 2 GND        → 板2GND和屏幕电源负极   信号与电源共地
LCD 3 CS         → 板2 GPIO8              片选，低电平有效
LCD 4 RESET/RST  → 板2 GPIO14             屏幕复位，低电平有效
LCD 5 DC/RS      → 板2 GPIO1              区分命令和数据
LCD 6 SDI/MOSI   → 板2 GPIO9              板2向屏幕发送数据
LCD 7 SCK        → 板2 GPIO7              SPI时钟
LCD 8 LED/BL     → 屏幕专用稳定3.3V       背光控制保持高，常亮
LCD 9 SDO/MISO   → 不接                    当前驱动只向屏幕写数据
LCD 10～14       → 不接                    当前不使用触摸
LCD SD卡接口     → 不接                    当前不使用SD卡
```

RESET是板2GPIO14，不是GPIO12，也不是开发板RST排针。当前没有软件背光控制，不把LED脚接GPIO12。35002的LED是控制输入，转接板有背光驱动电路，不是裸背光大电流电源引脚。

有的SPI屏把MOSI写成SDA：这里仍是SPI数据输入，接板2GPIO9，不能套用板1TCA的I2C SDA接法。当前屏幕采用480×320横屏、SPI0 mode0、2MHz；重接不用改横竖屏，也不用交换SCK/MOSI。

板1GPIO14是TCA SDA，板2GPIO14是屏幕RESET；它们在不同开发板上，不冲突、不互接。

## 9. 把乱线恢复的操作顺序

1. 全部断电，先给两块板和两颗TCA贴标签；用线标签标信号，红色留给正电源、黑色留给GND。建议把R200 5V轨、板1 3.3V轨、屏幕3.3V轨明确分开。
2. 万用表通断档确认面包板电源轨是否中间断开，两侧是否互通；靠线色不能保证连通。检查5V和3.3V没有误连，正负电源没有持续短路。
3. 先接板1与两颗TCA的电源、总线、地址，通电看0x20/0x21 probe成功；只用第一颗时0x21失败是预期，两颗都装时则需排查。不要把probe成功当全部外设通过。
4. 断电后接14个按键；通电每个按住、松开约0.5秒，S1～S5看对应Stage日志，上/下/左/右/OK/D1～D4看Extra key 1～9。松开应高、按下应低。没有屏幕业务动作时，先看物理输入日志。
5. 断电后接LED；当前正常板1程序的feedback初始化会依次短闪红、绿、黄，之后待机全灭。刚启动没看见或待机不亮，不能直接判断线；独立R200诊断包不包含这套反馈测试。
6. 断电接已确认的3.3V蜂鸣器：VCC→板1 3V3、GND→板1GND、IN→第一颗P03。它只在相应反馈动作被调用时响，不要求每次读卡都响。
7. 断电接R200的供电、共地、交叉TX/RX和天线；用已知读到过的标签检查EPC/RSSI及RX计数。UART初始化完成、模块有声都不能代替收到真实EPC。离线API包也可能不主动盘存，必须使用当前适合读卡的测试流程。
8. 单独检查板2与屏幕：先确认稳压输出3.3V，断电接齐，再一起通电。背光亮但无画面时，按RESET、CS/DC、SCK/MOSI、供电共地逐项核对，别先全部拆线或盲目重烧。
9. 两边分别正常后再测SLE；两板间不用补信号线。重接后看板1真实读到的标签数能否到板2显示，最后分别记录冷启动和板2单独复位后的恢复。

## 10. 本次解决的问题、原因、方法和证据边界

解决的是“当前元件应接哪块板、哪条电源、哪个引脚”不清：旧笔记把TCA SCL写过GPIO12、把LCD RESET写过GPIO12，又混有RC522旧工程和已过期的第二颗未装说明；GPIO编号、排针序号、TCA端口编号也容易混淆。

处理方法：先用CMake确定主工程和角色源码，再读取各驱动的引脚/方向/有效电平定义，用厂商PDF和实际接口图核对供电与排针，最后用较新的实板记录复核两颗TCA的存在和按键编号。统一成上述连接清单，不为了接线改变固件引脚。

新增的是本说明；本次没有重接实物、编译、烧录或证明当前乱线已恢复。此前R200间歇零回复的物理原因仍不能凭这次资料核对断定。蜂鸣器接法已根据用户本轮补充确认，仍需重接后的实物反馈验证。
