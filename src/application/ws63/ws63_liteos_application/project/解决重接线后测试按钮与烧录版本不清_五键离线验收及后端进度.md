## 3. 实際按钮顺序

1. **只放1张已知标签，按S1一次，松开。** 从日志`capture begins mode=S1`开始完整等10秒，不动标签、不按其他键。看`[R200 MULTI] ... started`、EPC/RSSI、停读日志与`final accepted unique=1`，板2最后Tags read为1。此轮通过后再做后面的测试。
2. **仍用同一张，窗口结束后再按S1。** 连做三轮检查重复性。每轮unique应为1；samples可能超过1，这是同一标签被重复读取。某轮0张、无RX、start/stop failed或错误计数增加时保存日志，先停下分析。
3. **放3张已知标签，按S1一次，等10秒。** 目标unique=3、板2Tags read=3。移开其他UHF标签，不通过时不直接上20张。
4. **只放1张，依次按S2、S3、S4、S5，每次等3秒结束再按下一个。** 每次板1mode与按键一致，有真实EPC，板2stage和最终tags对应。每轮仍是本地读卡测试，不是后端批准结果。
5. **扫描中切阶段：按S1，看到开始读卡后，在10秒结束前按S2。** 期望先停旧盘存，日志出现`STOP_SCAN before SELECT_MODE S2`、`SELECT_MODE request S2`，S2开始独立3秒窗口；被中断的旧S1不应有final accepted。本包验证本地状态模拟，真实HTTP先后仍待后端联调。
6. **20张规模测试最后做。** 先建立20个不同EPC清单，再将20张同时平铺或扇形置于有效读区，不叠压、不靠金属；固定摆位，按S1等10秒，结束后再按下一轮，共三轮。不能一张张轮流递到天线前代替同时盘存。每轮保存unique/20、samples和诊断计数；未达20如实记漏读。
7. **稳定性单独测试。** 不按键、不挪线静置10分钟，保存两板日志，检查自行重启/断链。随后只按板2真正的复位键，观察重新连接并恢复状态；将人为复位时间记下来。板1GPIO13对应的用户键不是复位键，不按它。

这一轮不按方向键、OK、D1～D4，也不把S5/D4当CP。LED/蜂鸣器若保留，正常feedback初始化会依次短闪三色LED；待机全灭和读卡时没有蜂鸣不等于失败，最终靠EPC、RX计数和LCD数量验收。
